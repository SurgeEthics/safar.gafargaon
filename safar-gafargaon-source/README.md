# সফর (Safar) - গফরগাঁও স্মার্ট ট্রান্সপোর্ট ও ইমার্জেন্সি সার্ভিস

গফরগাঁও উপজেলার জন্য নিবেদিত স্থানীয় স্মার্ট রাইড শেয়ারিং ও ডিজিটাল ট্রান্সপোর্ট প্ল্যাটফর্ম।

## 📁 প্রজেক্ট চালানোর নিয়মাবলী (How to Run):

### ১. প্রয়োজনীয় সফটওয়্যার:
- আপনার কম্পিউটারে **Node.js** (v18 বা এর উপরে) ইন্সটল থাকতে হবে। (ডাউনলোড লিংক: https://nodejs.org)
- VS Code অথবা যেকোনো কোড এডিটর।

### ২. ইন্সটলেশন ধাপসমূহ:
১. এই জিপ ফাইলটি যেকোনো ফোল্ডারে আনজিপ (Extract) করুন।
২. ফোল্ডারটি ওপেন করে টার্মিনাল (Command Prompt / PowerShell / Terminal) ওপেন করুন।
৩. নিচের কমান্ডটি দিয়ে সব ডিপেন্ডেন্সি ইন্সটল করুন:
   ```bash
   npm install
   ```
৪. অ্যাপটি চালু করতে নিচের কমান্ডটি রান করুন:
   ```bash
   npm run dev
   ```
৫. ব্রাউজারে `http://localhost:3000` ওপেন করলে আপনার সম্পূর্ণ অ্যাপটি চালু হয়ে যাবে!

### ৩. প্রোডাকশন বিল্ড তৈরি করার নিয়ম:
```bash
npm run build
```
এটি `dist/` ফোল্ডারে অপ্টিমাইজড এইচটিএমএল/সিএসএস/জাভাস্ক্রিপ্ট ফাইল তৈরি করবে, যা যেকোনো ওয়েব হোস্টিংয়ে (Vercel, Netlify, Firebase, cPanel ইত্যাদি) সরাসরি আপলোড করা যায়।

## 🚀 গিটহাব (GitHub) ও ক্লাউডফ্লেয়ারে (Cloudflare) লাইভ করার নিয়ম:

### ধাপ ১: GitHub-এ আপলোড:
1. GitHub-এ একটি নতুন রিপোজিটরি তৈরি করুন (যেমন: `safar-gafargaon`)।
2. আপনার আনজিপ করা ফোল্ডারে টার্মিনাল খুলে কমান্ড দিন:
   ```bash
   git init
   git add .
   git commit -m "Initial commit: Safar Gafargaon Complete App"
   git branch -M main
   git remote add origin https://github.com/আপনার-ইউজারনেম/safar-gafargaon.git
   git push -u origin main
   ```

### ধাপ ২: Cloudflare Pages-এ অটোমেটিক লাইভ করা (Frontend Web App):
1. [Cloudflare Dashboard](https://dash.cloudflare.com)-এ যান।
2. বামপাশের মেনু থেকে **Workers & Pages** -> **Create application** -> **Pages** -> **Connect to Git** সিলেক্ট করুন।
3. আপনার GitHub রিপোজিটরি (`safar-gafargaon`) সিলেক্ট করুন।
4. **Build settings**-এ দিন:
   - **Framework preset:** `Vite`
   - **Build command:** `npm run build`
   - **Build output directory:** `dist`
5. **Save and Deploy** বাটনে ক্লিক করুন। 
   - ব্যাস! Cloudflare স্বয়ংক্রিয়ভাবে অ্যাপটি লাইভ করে একটি ফ্রি ডোমেইন (`.pages.dev`) বা আপনার কাস্টম ডোমেইনে যুক্ত করে দিবে। 
   - ভবিষ্যতে আপনি GitHub-এ কোনো কোড পরিবর্তন বা পুশ করলেই Cloudflare নিজে নিজে আপডেট হয়ে লাইভ হয়ে যাবে!

### ধাপ ৩: Cloudflare Worker লাইভ লোকেশন ইঞ্জিন (ঐচ্ছিক - রিয়েল-টাইম WebSocket):
1. `cloudflare-worker` ফোল্ডারে যান:
   ```bash
   cd cloudflare-worker
   npx wrangler deploy
   ```
2. অথবা Cloudflare Dashboard-এ Workers তৈরি করে `cloudflare-worker/worker.js` এর কোডটি পেস্ট করে Deploy দিন।
